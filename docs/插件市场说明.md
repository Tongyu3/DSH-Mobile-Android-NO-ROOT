# 插件市场 · 使用说明

> 从 **0.1.13** 开始，App 里内置了一个插件市场：
> 在 **npm** 上搜索社区为 DeepSeek Harness 写的插件，点一下就能装。

---

## 一、入口在哪

**DSH 界面左上角鲸鱼图标 → 设置 → 拉到最下面 → 手机权限 → 插件市场**

（平板等宽屏设备：设置入口在**左下角的齿轮图标**，本机入口同样在分类列表最下面。）

设置页里现在有这几项，注意区分：

| 入口 | 里面是什么 |
|---|---|
| `API Key` | 填你的 DeepSeek API Key |
| `手机权限` | 其余全部本机设置的大类，点进去有下面这些 |

「手机权限」里面：

| 入口 | 里面是什么 |
|---|---|
| `手机控制` | **授权与开关**：无障碍守护、一次性授权、截图方式、操作后端；也包括**应用白名单** |
| `插件市场` | 装/卸 DSH 插件（就是这篇说明讲的） |
| `常驻服务` | 让本地代理常驻自启（CPA / CLIProxyAPI 配在这里） |
| `内核升级` | 检测并升级容器里的 DSH |
| `桌面图标` | 换桌面快捷方式配色 |
| `环境安装源` | 中国大陆 / 非中国大陆的镜像源 |
| `插件安全模式` | 插件把界面卡住时的自救（见文末常见问题） |
| `复制运行日志` | 遇到问题（加不上文件 / 界面白屏）时点一下，然后粘贴发给开发者 |

## 二、界面怎么用

打开后你会看到：

```
🧩 插件市场
已安装 3 个：@deepseek-ai/dsh-base、@deepseek-ai/dsh-web-app、dsh-phone

[ 搜索插件（留空 = 全部） ]  [搜索]

dsh-cost-meter  1.7.40                    [ 安装 ]
DeepSeek Harness 会话费用统计插件…

dsh-whale-widget  0.3.16                  [ 安装 ]
DSH Web 界面右下角的 DeepSeek 余额小鲸鱼挂件…

...

[ 刷新已安装列表 ]
```

- **搜索框留空**点「搜索」= 列出全部（按热度/相关度排序，一次 25 条）
- 输入关键词（比如 `主题`、`搜索`、`memory`）再搜，会在这个范围内筛
- 已经装过的显示 **✅已装**，按钮变成 **卸载**
- 每条都显示**包名、版本、一句话描述**——装之前先看清是什么

### 装一个插件

1. 点目标插件那一行的 **「安装」**
2. 弹出确认框，**认真读一遍**（见下面第四节），确认就点「安装」
3. 等进度框消失。第一次装可能要下依赖，慢一些（实测一个小插件约 5 秒）
4. 装完会问你要不要**现在重启 DSH** —— 建议点是

> ⚠️ **必须重启 DSH 插件才会生效。** 插件是在 DSH 启动时按 profile 加载的，
> 装完不重启，界面上什么都不会变。

### 卸载

点 **「卸载」** → 确认 → 重启 DSH。

`@deepseek-ai/dsh-base` 和 `@deepseek-ai/dsh-web-app` 是 DSH 自己的必需组件，
代码里做了保护，卸载会被拒绝。其余都能卸。

## 三、插件从哪来的

**直接查 npm 官方的 registry**，筛选带 `dsh-plugin` 标签的包。

这是 DSH 官方的插件发现机制——插件作者发布时给仓库/包打上这个标签，
所以不需要我们维护一份清单，也不会出现过期列表。
（写这份说明时，npm 上有 **6270+** 个这样的包。）

**需要联网**：搜索要访问 npm，安装要下载插件和它的依赖。
容器里的网络和你手机是同一套。

---

## 四、⚠️ 安全上必须说清楚的事

**装一个插件 = 让它的代码在你的手机上运行。**

插件跑在 App 的 Linux 容器里，而容器是以 `danger-full-access` 模式运行的
（这是必需的：容器里没有可用沙箱，不这么设 agent 完全没法干活）。
所以插件**能干的事很多**——包括读写你手机共享存储里的文件。

**因此：**

- 只装你**信得过**的插件。不确定就先去看它的源码/仓库。
- App 在安装前**强制弹确认框**，把上面这件事原样告诉你。
  我们不替你判断某个插件值不值得信任——那是你的决定。
- 插件**不能绕过应用白名单**。白名单是 App 侧强制的边界，插件改不了。
  但请注意：白名单管的是"agent 能操作哪些 App"，**管不了插件读文件**。

> 如果你完全不想要插件，什么都不点就行——市场只是个入口，
> 不会自己装任何东西。

## 五、自带的插件：`dsh-phone`

**这个不用你装，App 自带并在首次启动时自动装好。** 它出现在插件列表里是正常的。

它把"操作手机"的能力做成了 DSH 的原生工具，agent 不用再靠敲命令行：

| 工具 | 作用 |
|---|---|
| `phone_status` | 当前前台应用、白名单、各项能力状态 |
| `phone_screenshot` | **截屏**并存成 PNG（微信/QQ 这类只能靠它看） |
| `phone_ui` | 读当前界面控件树（含坐标） |
| `phone_tap` / `phone_click` | 按坐标点击 / 按文字点击 |
| `phone_swipe` | 滑动 |
| `phone_text` | **输入文字**（微信会自动改用内置输入法） |
| `phone_key` | 返回 / 主页 / 多任务 / 通知栏 |
| `phone_open` | 启动白名单内的应用 |
| `phone_ime` | 输入法状态 / 切过来 / **还回去** |

它还会写一份自检结果到 `/sdcard/.dsh-phone/plugin-loaded.txt`，长这样：

```
plugin=dsh-phone
tools=10
registered=10
failed=[]
names=phone_status,phone_screenshot,...
```

如果 `registered` 不等于 `tools`，说明有工具没注册成功，可以在 DSH 里问 agent。

### 另一个自带插件：手机文件（`dsh-phone-files`）

同样自带、同样不用你装。它给 DSH 的**右侧栏**加了一个「**手机文件**」标签页：

| 按钮 | 作用 |
|---|---|
| ↑ 上一级 | 往上一层目录 |
| 根目录 | 回到 `/storage/emulated/0` |
| 刷新 | 重新列一遍 |
| **加入会话** | 把选中的文件**路径**写进输入框 |

用法：点开标签页 → 逐个点文件名选中（可多选）→ 点「加入会话」→
路径就出现在输入框里，后面接着写你想让它干什么，例如
「把这个文件转成 markdown」。

> 它是**只读**的：只能看和选，不能删、不能改、不能移动 ——
> 这是有意的，避免误触把手机里的文件弄没了。
>
> 目前插入的是**文件路径**，不是文件本体。DSH 能读到该路径
> （共享存储是挂进容器的），所以让 agent 自己去读就行。

## 六、常见问题

**Q：搜不到东西 / 一直转圈**
A：需要联网。另外搜索走的是 npm 官方 registry，网络受限时会失败。
失败时界面会直接显示错误原因。

**Q：安装卡住很久**
A：第一次装某个插件要下载它和它的依赖。实测一个小插件约 5 秒；
依赖多的会久一些。超过 3 分钟会超时报错，可以重试。

**Q：装完了但没看到变化**
A：**必须重启 DSH**。点安装完成对话框里的「重启 DSH」，
或者直接退出 App 再打开。

**Q：提示装不上 / 退出码不是 0**
A：把错误原文发出来（对话框里会显示）。常见原因是
该包依赖的某个东西在当前环境里装不了，或者包本身不是给 DSH 用的。

**Q：卸了插件，之前装的东西还在吗**
A：插件在 profile 里的记录会被移除，重启后不再加载。
它自己写到别处的文件（比如 `/sdcard` 里的）不会被删。

**Q：会不会把我手机装坏**
A：插件在容器里跑，碰不到系统分区，也碰不到其他应用的私有数据。
但它**能读写你共享存储（`/sdcard`）里的文件**——
装之前请确认你信任这个插件。

**Q：`dsh-phone` 能卸载吗**
A：能，但不建议——卸了 agent 就没法操作手机了。
（下次 App 更新时它还会被自动装回来。）

**Q：装了个插件之后，DSH 界面白屏 / 一直显示 `Failed to load plugins`，进不去了**
A：这是**插件与当前 DSH 版本不兼容**，不是 App 坏了。
**0.2.7 起你什么都不用点**：界面一发现起不来，App 就自动把可疑的插件停掉并重启 ——
报错里点名了就只停那一个，没点名就把所有第三方插件先停掉（官方包和自带插件不受影响）。
界面回来后，你可以在「DSH 设置 → 手机权限 → **插件安全模式**」里逐个恢复，
找到是哪个插件的问题。

**Q：安全模式停用的插件去哪了？还能回来吗**
A：能。停用时 App 做两件事：把它从加载列表里摘掉，
并把它的**包目录整个挪到一边**（`node_modules/.dsh-disabled/`），
所以它是真的不会被加载 —— 不是"只是界面上关掉了"。
点「**恢复全部**」会把包目录和依赖声明原样挪回去，等于**回到装这个插件之前/之后**的状态。

**Q：什么时候会自己停用插件**
A：**第一次**界面起不来就动手（不用你点）。自动动手**最多 2 次** ——
如果根本不是插件的问题（容器/网络），"停用+重启"救不回来，就不能无限重启下去，
所以超过 2 次会停下来弹个面板，让你决定，并提示「复制运行日志」。

## 七、给插件作者

你的插件要出现在这个市场里，只需要：

1. 按官方规范做成 npm 包，`package.json` 里声明
   `"dsh": { "bundle": { "patch": "./cordis.patch.yml" } }`；
2. 给包打上 **`dsh-plugin`** 关键词（和仓库 topic）。

发布后不用做别的——市场直接查 npm，搜得到就能装。

本机自带的 `dsh-phone` 就是一个完整例子，源码在仓库的 `plugin/dsh-phone/`：
零依赖、纯 JS、没有构建步骤。
