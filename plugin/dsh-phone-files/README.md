# dsh-phone-files · 手机文件

DSH 右侧栏里的一个**文件管理器**标签页：浏览手机存储（容器里的 `/sdcard`），
多选文件/图片，一键加进当前会话。

## 用法

1. DSH 右侧栏 → 新标签 →「**手机文件**」；
2. 点文件夹进入、点「↑ 上一级」返回；
3. 点文件名多选（选中会高亮并显示「已选」）；
4. 点右上角「**加入会话 (N)**」→ 路径被写进输入框，按回车发送即可。

## 它依赖 App 注入的两个桥

这个面板只在本 App（DeepSeek Harness 安卓版）里有完整功能 —— 因为"读手机文件"
和"写进输入框"这两件事，只有 App 能做到：

| 桥 | 谁提供 | 作用 |
|---|---|---|
| `window.DshAndroid.listFiles(path)` | `MainActivity.AppBridge` | 列目录，返回 `[{name,dir,size,path}]`；App 侧把路径**限制在共享存储内** |
| `window.__dshPhoneFilesInsert(paths)` | `tools/patch.js` | 把选中的路径写进输入框（DSH 的编辑器是 React 受控的 contenteditable，只能走 `execCommand('insertText')`） |

两个桥都不在时（比如在桌面版 DSH 上装了这个插件），面板会显示一句提示，
而不是白屏或报错。

## 为什么宿主侧是空的

`lib/index.js` 只有一个空的 `apply()`。列目录与插入都由上面的桥完成；
走 DSH 的 Remote/typert 那一套当然更"正统"，但那套东西的用途是跨进程/跨平台，
而这个面板天生只在这台手机上工作 —— 桥更直接，出问题也更好查。

## 边界（刻意的）

- **只读**：这一版不做删除/移动/重命名。要动文件请用系统的文件管理器，
  或者让 agent 用命令去做（那样还有对话记录可查）。
- **不给隐藏文件**：以 `.` 开头的条目不列（面板保持干净）；需要的话可以加开关。
- **不越界**：路径只允许在共享存储内，App 侧做了规范化 + 前缀校验，防目录穿越。
